# 方法论与判据

框架出处：<https://share.note.sx/lhdvvvwl>（《六大经济指标与四大择时模型》）。
结构是「**先看周期在哪，再看价格贵不贵，最后等技术面给信号**」。

---

## 一、六个指标

| 指标 | 角色 | 英文全称 | 解读要点 |
|---|---|---|---|
| PMI | 领先 | Purchasing Managers' Index | 50 荣枯线，>50 扩张 |
| 社融 | 领先 | Total Social Financing | 增速上行 = 借钱意愿强，预示经济向好 |
| M2 | 领先 | Broad Money Supply | 货币总量，越大贬值越快 |
| GDP | 同步 | Gross Domestic Product | 增速上行则经济看好 |
| PPI | 领先 | Producer Price Index | >3% 成本高、利润受损；触底回升是盈利拐点 |
| CPI | 滞后 | Consumer Price Index | 1%~3% 正常，<1% 通缩，>3% 通胀压力 |

## 二、四个模型

| 模型 | 类型 | 核心变量 | 判定 |
|---|---|---|---|
| ① 经济周期 | 定性 | GDP × CPI | 美林时钟四象限 |
| ② 货币周期 | 定性 | 社融 × PPI | 四阶段轮动：股票 / 商品 / 现金 / 债券 |
| ③ 情绪周期 | 定量 | ERP = 100/PE − 10Y国债 | >6% 买入区，<3% 高估区 |
| ④ 技术指标 | 定量 | **RSI6**（RSI14 仅参考） | >80 超买，<20 超卖 |

权重：`{"cycle": 0.25, "money": 0.30, "erp": 0.25, "rsi": 0.20}`。
货币周期给最高权重——对 A 股，信用扩张比经济数据更直接。

### 两张时钟图必须坐标系同构

象限位置由**两条轴的方向唯一决定**，不能靠搬动格子来「调整顺序」。

| 位置（顺时针） | 模型① | 模型② |
|---|---|---|
| 1 左上（横低·纵高） | 复苏 | 转向复苏 |
| 2 右上（横高·纵高） | 过热 | 趋于过热 |
| 3 右下（横高·纵低） | 滞胀 | 增长趋缓 |
| 4 左下（横低·纵低） | 衰退 | 步入衰退 |

两张图都要「横轴放价格（CPI / PPI）、纵轴放量（GDP / 社融）」。
曾经模型② 把社融放横轴、PPI 放纵轴，四格名称没变但顺时针顺序逆着周期走，读起来全是反的。
**改标签解决不了，只能换轴。**

## 三、方向判定的两条规则

宏观单月噪声大，所以：

1. **短期动量优先**：先看最近两期变化，超过噪声阈值 `max(标准差 × 0.12, 0.02)` 就采纳
2. **中期趋势兜底**：否则退回「近 3 期均值 vs 前 3 期均值」

为什么不直接比均值：刚拐头的指标会被「近 3 期 vs 前 3 期」判反，方向迟滞一个季度。

### 通胀象限的绝对水平约束

`CPI 0.9%` 短期反弹不能叫「通胀高企」，否则美林时钟会把低通胀误判成滞胀。所以：

- `<1%` 一律归低通胀
- `>3%` 一律归高通胀
- `1%~3%` 才看方向

**注意**：画图时轴标签高亮必须用**校正后的象限方向**，不能直接用原始 `trend.dir`，否则 CPI<1% 时轴标签会亮在反侧，与高亮格自相矛盾。

## 四、为什么用 RSI6 而不是 RSI14

框架原文只写「RSI」，没指定周期。用沪深 300 近 2 年 486 个交易日实测，同一 20/80 阈值下：

| 阈值 20/80 | RSI14 | RSI6 |
|---|---|---|
| ≤20（超卖） | 1 天 · 0.2% | 18 天 · 3.6% |
| ≥80（超买） | 4 天 · 0.8% | 27 天 · 5.5% |
| 合计 | **5 天** | **45 天** |
| 标准差 | 11.1 | 16.9 |

RSI14 两年只响过 5 次，信号等于哑的。RSI6 配同样阈值回到 3.6% / 5.5% 的可用水平，且**不必改阈值**（尊重原框架）。

配套调整：
- 临界带从 ±5 放宽到 **±8**（RSI6 标准差约为 RSI14 的 1.5 倍，保持「临界」触发概率等价）
- 第④层门槛 `RSI6 ≤ 35`（实测约 15% 分位，约每 7 个交易日出现 1 天）
- RSI14 保留展示，标注「参考」，不参与评分

**通用判据**：先算阈值触发频率，落在 2%~8% 才可用；否则调窗口，不要调阈值。

## 五、四层逐级确认

四个布尔门，命中数 0~4 决定仓位档位：

1. ① 经济周期底部
2. ② 货币周期底部
3. ③ 情绪周期高位（便宜）
4. ④ RSI 超卖

```
综合仓位 = 连续评分 × 0.7 + 共振层数 / 4 × 100 × 0.3
```

3 层 = 「接近买点，可分批建仓」；4 层才是全仓级信号。
第②层往往是关键缺项：社融企稳回升通常先于盈利改善，是股票见底的必要条件。

## 六、参考水平线：判定顺序（最容易出错的地方）

框架里反复出现「PMI 50」「CPI 1%~3%」「PPI 3%」这类水平线，但**一条线为什么是这个数，几乎没人验证**。
`tm/refs.py` 用 2018 年以来的真实数据算「该线被触发的月份，之后 12 个月沪深 300 的平均收益」，
再减去未触发月份的平均收益（`gap`）。

### 判定必须按这个顺序，且不能跳步

```
样本不足（n<24 或命中<6）        → 不作阈值
触发频率极端（>92% 或 <8%）      → 无区分力
|整体差| < 4pct                  → 无区分力
命中月份只有一段                  → 单段行情，不成立
多段但方向相反                    → 不成立（关键！）
最大聚类占比 > 75%               → 集中于一段行情，不成立
否则才允许「可作阈值」
```

### 为什么「逐段同向」是硬条件

初版只看整体差值，把 **CPI≥2** 判成「有区分力」（整体 +8.7pct）。
按时间切成独立时段后现原形：**2018-2020 差 +15.5，2021-2023 差 −10.1，方向相反**。
两次独立验证给出相反答案 = 没有结论。只看整体，等于让一段行情替另一段说话。

### 为什么用「最大聚类占比」而不是「连续段数」

- PPI>3% 的两段分属 2018 与 2021 两次**独立**周期，段数 = 2，那是两次独立验证，很有力
- M2<8% 的 18 个月散在 4 段里，却全挤在 2023—2026 一个窗口内，段数掩盖了「其实只有一段行情」

聚类规则：命中月份的序号（年×12+月）间隔 ≤ 12 个月算同一段。

### 九条线的实测结论（2018-01 起，94 个有效月）

| 线 | 逐段差 | 整体 | 结论 |
|---|---|---|---|
| PMI ≤50 | +20.6 / +2.0 | +7.0 | 弱区分力，仅背景（跌破后反而更好，因为已跌过一轮） |
| CPI ≥2 | **+15.5 / −10.1** | +8.7 | **反向，不可用** |
| CPI ≥3 | +26.9（单段 8 月，2019-20 猪周期） | +26.9 | 单段行情 |
| CPI ≤1 | −2.8（单段 45 月） | −2.8 | <4pct 无区分力 |
| **PPI ≥3** | −6.8 / −24.3 | −17.8 | ✅ 两段同向，可作阈值 |
| **PPI ≤0** | +21.5 / +10.0 | +13.8 | ✅ 两段同向，可作阈值 |
| GDP ≤5 | +11.0 / −13.9 / +10.8 | +0.6 | 三段乱序 |
| M2 ≤8 | +13.5(4月) / +17.1(14月,78%) | +16.3 | 集中在一段 |
| 社融 ≤10 | −29.0(2月) / +2.6(35月,95%) | +0.9 | 无区分力 |

**结论：九条线只有 PPI 的两条通过。**

- **PPI 3% 最扎实**：阈值从 0% 逐级抬到 5%，收益差单调放大（−13.8 → −23.5），不是挑出来的点位
- **PMI 50 是定义不是信号**：50 是官方定义的荣枯分界，只有描述意义；实测跌破 50 后市场反而更好
- **CPI 3% 已过时**：2025、2026 年政府工作报告的 CPI 目标已从「3% 左右」下调到「2% 左右」

线上照画（用户要求九条都画），但只有 PPI 两条按阈值语义使用，其余仅作背景，卡片 chips 只标「是否触发」。

### 分级依据

每条线都要标 `level`：

- `定义性`：官方定义（如 PMI 50）
- `政策目标`：政府工作报告年度目标，**会逐年移动**，不能当跨年固定阈值
- `经验值`：无官方口径，只能靠统计区分力说话

### 新增线条时必须做的事

1. 标注 `level` 与 `basis`（依据来源）与 `caveat`（反向证据或失效条件）
2. 跑 `verify_refs.py` 看逐段结果，只有通过全部条件才修改 `role` 或让它参与判定
3. **不要为了让线「看起来有效」而调整聚类窗口或阈值**——换阈值型指标必须先对齐口径
